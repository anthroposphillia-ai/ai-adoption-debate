# 그건 안 됩니다 — AI 도입 회의에서 반복되는 말들

AI 도입을 두고 벌어지는 회의에는 늘 같은 말들이 등장합니다. "보안 때문에 안 됩니다." "개인정보가 들어갑니다." "로컬 LLM 쓰면 되잖아요." "AI가 거짓말을 합니다."

이 책은 그 말들을 하나씩 붙잡고 세 가지를 봅니다. 그 말이 실제로 가리키는 것이 무엇인지, 어디까지가 사실이고 어디부터가 관성인지, 그리고 그 말이 놓치고 있는 것은 무엇인지. AI를 옹호하는 책이 아니고, 보안을 무시하는 책도 아닙니다.

결론을 미리 정해두지도 않습니다. 어떤 장에서는 도입을 미루는 쪽이 옳고, 어떤 장에서는 미루는 쪽이 비용을 외면하고 있습니다. 말 하나를 끝까지 따라가면 어느 쪽인지가 드러납니다.

## 이 책이 답하는 질문

- "보안 때문에 안 된다"는 말은 정확히 무엇을 뜻하는가
- 로컬 LLM을 쓰면 보안 문제가 해결되는가
- 개인정보를 빼면 나머지는 그대로 넣어도 되는가
- AI를 쓰지 않아서 생기는 손실은 누가 계산하는가
- AI 도입을 가로막는 것은 기술인가, 책임 구조인가

## 읽는 방법

각 장은 회의에서 반복되는 말 하나를 다룹니다. 순서대로 읽어도 되고, 지금 우리 회의를 막고 있는 말이 있는 장부터 읽어도 됩니다. 각 장은 그 자체로 결론이 서도록 썼습니다.

- **AI를 도입하려는 사람** — 반대를 설득하는 대신 반대의 근거를 분해할 수 있게 됩니다.
- **AI를 막고 있는 사람** — 막는 근거를 더 정확하게 만들 수 있습니다. 부정확한 근거는 존중받지 못합니다.
- **결정하는 사람** — 도입과 미도입의 비용을 같은 저울에 올리는 기준을 얻습니다.
